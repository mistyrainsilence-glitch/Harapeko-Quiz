# Discord クイズBot 操作マニュアル

Discord上でクイズを出題し、回答を他の参加者に見せずに集めて、問題ごとの正解者と最終ランキングを集計するBotです。

- 出題形式：自由入力 ／ ○× ／ 選択式（2〜4択）
- 回答は本人と運営（出題者・集計者）しか見られません
- 締切になると自動で正誤判定し、運営専用チャンネルに結果を投稿します
- 全問終了後、正解数によるランキングと各問の○×表を出せます
- 運営用の操作パネルのボタンで、コマンドを打たずに出題・集計ができます

## 1. ファイル構成

設置場所：`D:\tools\DiscordBot\harapeko-quiz`（以下「ルートフォルダ」）

```
harapeko-quiz\
├ start.bat                 起動用ファイル（トークンなどの設定入り）
├ README.md                 このマニュアル
├ app\
│ ├ quiz_bot.py            Bot本体のプログラム
│ └ requirements.txt       必要なライブラリの一覧
├ data\
│ └ quiz.db                問題・回答・設定のデータ（自動で作成）
└ samples\
  ├ questions_sample.xml   問題リスト（XML）の見本
  └ questions_sample.json  問題リスト（JSON）の見本
```

| フォルダ・ファイル | 注意 |
|---|---|
| `start.bat` | **他人に渡さない・上書きしない**（トークンが書かれています） |
| `app\` | 更新時は、この中の `quiz_bot.py`（と `requirements.txt`）を上書きします |
| `data\` | Botが自動で作成します。**中の `quiz.db` は削除しない**でください |
| `samples\` | 書き方の見本です。コピーして問題リストを作ってください |

## 2. 初回セットアップ

初回だけ必要な作業です。

### 2-1. Pythonのインストール

1. https://www.python.org/downloads/ からインストーラーをダウンロードして実行します。
2. 最初の画面で **「Add python.exe to PATH」に必ずチェック**を入れてからインストールします。

### 2-2. Botアカウントの作成

1. https://discord.com/developers/applications を開き、「New Application」でアプリを作成します。
2. 左メニューの「Bot」を開き、「Reset Token」でトークンを取得して控えます。
   **トークンはBotのパスワードです。絶対に他人に見せないでください。**

### 2-3. Botをサーバーに招待

1. Developer Portal の左メニュー「OAuth2」を開きます。
2. 「OAuth2 URL Generator」の SCOPES で **`bot` と `applications.commands` の両方**にチェックします。
3. BOT PERMISSIONS で次の4つにチェックします。
   - View Channels
   - Send Messages
   - Embed Links
   - Read Message History
4. 一番下に表示されたURLをブラウザで開き、対象のサーバーを選んで認証します。

### 2-4. Discordサーバーの準備

| 作るもの | 設定 |
|---|---|
| ロール「クイズ運営」 | 出題者・集計者に付与する |
| チャンネル `#クイズ出題` | 全員が閲覧可能。回答者のメッセージ送信は禁止にするとネタバレ防止になる |
| チャンネル `#クイズ集計` | 「クイズ運営」ロールとBotだけが閲覧可能にする。集計結果が投稿される |
| チャンネル `#クイズ操作` | 「クイズ運営」ロールとBotだけが閲覧可能にする。操作パネルを置く（`#クイズ集計` と兼用も可） |

### 2-5. IDの取得

1. Discordのユーザー設定 →「詳細設定」→「開発者モード」をオンにします。
2. サーバーアイコンを右クリック →「サーバーIDをコピー」
3. `#クイズ集計` を右クリック →「チャンネルIDをコピー」

### 2-6. start.bat の作成

ルートフォルダにメモ帳で次の内容を書き、`start.bat` という名前で保存します。

```bat
@echo off
cd /d %~dp0
set DISCORD_TOKEN=ここにBotのトークン
set GUILD_ID=ここにサーバーID
set RESULT_CHANNEL_ID=ここに集計チャンネルのID
py app\quiz_bot.py
pause
```

運営ロールの名前を「クイズ運営」以外にする場合は、`py app\quiz_bot.py` の行の前に `set STAFF_ROLE=ロール名` を追加します。

### 2-7. ライブラリのインストール

1. ルートフォルダをエクスプローラーで開きます。
2. アドレスバーに `cmd` と入力してEnterを押します（黒い画面が開きます）。
3. 次のコマンドを実行します。

```
py -m pip install -r app\requirements.txt
```

## 3. Botの起動・停止・再起動

### 起動

`start.bat` をダブルクリックします。
黒い画面に「ログインしました: ○○」と表示されれば成功です。

### 停止

次のどちらかの方法で停止します。

- 黒い画面を選択して **Ctrl + C** を押し、「バッチ ジョブを終了しますか (Y/N)?」に `Y` と入力してEnter
- 黒い画面を右上の **×ボタン**で閉じる

### 再起動

停止したあと、もう一度 `start.bat` をダブルクリックします。

### 注意

- **Botは1つだけ起動してください。** 同じPCで2つ目を起動しようとすると、「このBotはすでに起動しています」と表示されて終了します。
- **黒い画面を閉じたり、PCがスリープしたりするとBotは止まります。** 大会中はPCがスリープしない設定にしてください。
- 回答受付中に止まった場合、再起動すれば締切タイマーと保存済みの回答は元に戻ります。ただし、**停止中に押されたボタンの回答は記録されません**（回答者には「インタラクションに失敗しました」と表示されます）。
- 停止中に締切が過ぎた問題は、再起動直後に締め切られ、集計されます。

## 4. ソースの更新方法

1. Botを停止します。
2. `app\quiz_bot.py` を `quiz_bot_old.py` などにリネームしてバックアップします。
3. 新しい `quiz_bot.py`（と `requirements.txt`）を `app` フォルダに置きます。
4. 新しいバージョンで必要なライブラリが変わった場合に備えて、ルートフォルダのアドレスバーに `cmd` と入力して開いた黒い画面で、次のコマンドを実行します。
   ```
   py -m pip install -U -r app\requirements.txt
   ```
5. `start.bat` をダブルクリックして起動します。
6. 新しいコマンドやボタンが表示されない場合は、Discordアプリで **Ctrl + R** を押して再読み込みします。

`start.bat` と `data` フォルダは上書きも削除もしないでください。
ソースの更新は大会の前に済ませ、大会中は再起動しないのが安全です。

## 5. 大会当日の流れ

### 運営（出題者・集計者）

基本の操作は、`#クイズ操作` の操作パネルのボタンで行います（パネルの設置方法は「6. 操作パネル」を参照）。

1. **起動**：Bot担当が `start.bat` を起動します。
2. **準備**：前回のデータが残っていれば、パネルの「🗑️ リセット」を押します。
3. **問題の登録**：問題リストを使う場合は、パネルの「📂 ロード」でXMLファイルをアップロードします。
4. **出題**：
   - 登録済みの問題を1問ずつ → 「⏭️ 次の問題」
   - 登録済みの問題を自動で順番に → 「🤖 オート出題」（「オート出題」を参照）
   - その場で問題を作る → 「📝 自由入力で出題」「⭕ ○×で出題」「🔤 選択式で出題」のいずれかを押し、表示されたウィンドウに入力
5. **集計**：締切になると、`#クイズ集計` に正解者・不正解者の一覧が自動で投稿されます。
6. **補正**：表記ゆれなどで正解にしたい回答があれば、`/quiz accept` か `/quiz judge` で修正します。
7. **正解発表**：パネルの「📢 正解発表」を押すと、正解・補足・正解者が発表されます。正解発表をするまで、次の問題は出題できません。オート正解発表をONにしておけば、締切から設定した秒数後に自動で発表されます。
8. 4〜7を繰り返します。残りの問題数はパネルで確認できます。
9. **結果発表**：全問終了後、パネルの「🏆 結果発表」を押すと、`#クイズ出題` にランキングが投稿されます。
10. **終了**：Bot担当がBotを停止します。

正誤の修正（`/quiz accept`・`/quiz judge`）など、パネルにない機能はコマンドで行います。運営コマンドの入力内容（正解など）は、実行した本人にしか表示されません。

### 回答者

| 形式 | 回答方法 |
|---|---|
| 自由入力 | 「回答する」ボタン → 入力欄に答えを書いて送信 |
| ○× | 「○」か「×」のボタンを押す |
| 選択式 | 「A：〜」「B：〜」などのボタンを押す |

- 自分の回答は自分にしか表示されません。
- 締切までは何度でも回答を変更できます（最後の回答が有効）。
- 締切はメッセージに「あと○秒」のように表示されます。

## 6. 操作パネル

### 設置方法（最初の1回だけ）

1. 運営だけが見られるチャンネル（`#クイズ操作` など）を開きます。
2. 次のコマンドを実行します。`channel` には問題を出題するチャンネルを指定します。
   ```
   /quiz panel channel:#クイズ出題
   ```
3. ボタン付きの操作パネルが投稿されます。必要に応じてピン留めしてください。

パネルはBotを再起動しても使い続けられます。パネルのメッセージを削除した場合は、もう一度 `/quiz panel` で設置してください。同じチャンネルで `/quiz panel` を実行し直すと、古いパネルは自動で削除されます。

**パネルは常にチャンネルの一番下に表示されます。** パネルのチャンネルに操作の記録や会話などが投稿されると、約2秒後にパネルが投稿し直され、一番下に移動します。

**ボタンは「クイズ運営」ロールの人だけが押せます**（ほかの人が押しても「使えません」と表示されるだけです）。ただし、パネルにはこれから出題する問題の冒頭が表示されるため、**必ず運営だけが見られるチャンネルに設置してください**。全員が見られるチャンネルに設置しようとすると、Botが警告を表示します。

### 進行状況の表示

パネルには次の内容が表示され、出題・締切・ロード・リセットのたびに自動で更新されます。

- 登録済みの問題数、出題済みの問題数、**残り（未出題）の問題数**
- 回答受付中の問題と締切までの時間
- これから出題する問題の一覧（先頭10問まで）
- 👉 次の操作（「第3問の『正解発表』をしてください」など、次に押すボタンの案内）

### ボタン

ボタンは4つのグループに分かれています。

**📝 出題**

| ボタン | 内容 |
|---|---|
| 📝 自由入力で出題 | 自由入力の問題の入力ウィンドウが開きます |
| ⭕ ○×で出題 | ○×問題の入力ウィンドウが開きます |
| 🔤 選択式で出題 | 選択式（2〜4択）の問題の入力ウィンドウが開きます |
| ⏭️ 次の問題 | ロードした問題リストから、次の1問を出題します |
| ⏹️ 締切 | 確認ダイアログが表示され、「締め切る」を押すと受付中の問題をすぐに締め切ります |
| 🤖 オート出題 | OFFのときに押すと設定ウィンドウが開き、ロードした問題を順番に自動で出題します。ONのときに押すと、停止の確認ダイアログが表示されます |

**📢 正解発表**

| ボタン | 内容 |
|---|---|
| 📢 正解発表 | 最後に締め切った問題の正解を、`#クイズ出題` で発表します（押すとすぐに発表されます）。回答受付中と発表済みのときは押せません |
| ⏱️ オート正解発表 | OFFのときに押すと秒数の設定ウィンドウが開き、ONになります。ONのときに押すと、停止の確認ダイアログが表示されます |
| ⚙️ 表示設定 | 正解発表に表示する項目を、チェックボックスで選べます |

**🗂️ 問題の管理**

| ボタン | 内容 |
|---|---|
| 📂 ロード | ファイル選択ウィンドウが開きます。XMLファイル（JSONも可）を選ぶと問題が登録されます |
| 🗑️ リセット | 確認ダイアログが表示され、「本当にリセットする」を押すと全データを消去します |

**🏆 最終結果**

| ボタン | 内容 |
|---|---|
| 🏆 結果発表（最終順位） | `#クイズ出題` に最終ランキングを投稿します。データは消えません |

ONになっているオート機能のボタンは緑色になり、「オート出題：ON（10秒後）」のように設定が表示されます。

### 出題ウィンドウの書き方

| 項目 | 自由入力 | ○× | 選択式 |
|---|---|---|---|
| 問題文 | 必須（Enterで改行できます） | 必須 | 必須 |
| 選択肢 | なし | なし | 1行に1つずつ、2〜4行（上から A・B・C・D） |
| 正解 | 答えを入力。複数なら `富士山\|ふじさん` | ○ か × を選ぶ | A〜D から選ぶ |
| 補足（任意） | 正解発表のときに表示する補足 | 同左 | 同左 |
| 回答時間 | 空欄なら60秒 | 空欄なら30秒 | 空欄なら30秒 |

入力ウィンドウを送信すると、すぐに出題されます。入力に誤りがあるとエラーが表示され、「入力し直す」を押すと、入力内容が残った状態でウィンドウが開きます。

### 正解発表と表示設定

「📢 正解発表」を押すと、`#クイズ出題` に正解が発表されます。最初の設定では、次の内容が表示されます。

```
📢 第2問の正解発表
問題：富士山の高さは3000メートル以上である。○か×か？
正解：○
補足：富士山の標高は3776メートルのため。
正解者は 12人（回答 20人）でした！

⭕ 正解者（回答が早い順）
・Aさん（3.2秒）
・Bさん（5.8秒）
・…
```

**表示する項目は、「⚙️ 表示設定」で変更できます。** 押すとチェックボックスの一覧が開くので、表示したい項目にチェックを入れて送信します。

| 項目 | 内容 | 最初の設定 |
|---|---|---|
| 問題文 | 問題の文章 | 表示 |
| 選択肢 | 選択式の問題の選択肢 | 表示 |
| 正解 | 正解 | 表示 |
| 補足 | 出題時に登録した補足（登録がある問題のみ） | 表示 |
| 正解人数・回答人数 | 「正解者は12人（回答20人）でした！」 | 表示 |
| 選択肢ごとの回答人数 | ○×・選択式の内訳（例：A：3人　B：12人） | 非表示 |
| 正解者の名前 | 回答が早い順の一覧 | 表示 |
| 正解者の回答時間 | 正解者の名前の横に表示（例：3.2秒） | 表示 |
| 不正解者の名前 | 不正解者の一覧 | 非表示 |
| 不正解者の回答 | 不正解者の名前の横に表示（例：Cさん：エベレスト） | 非表示 |

- 設定は、次の正解発表から反映されます。Botを再起動しても、リセットしても設定は残ります。
- 設定を変更すると、誰が何を表示する設定にしたかがパネルのチャンネルに記録されます。
- 補足は、出題ウィンドウの「補足」欄、または問題リストの `<note>` で、出題時に登録します。
- 「最後に締め切った問題」以外の正解を発表したいときは、`/quiz reveal` を使います。

### オート出題

ロードした問題リストを、上から順番に自動で出題します。

1. 「🤖 オート出題：OFF」を押します。
2. 設定ウィンドウで、**正解発表から次の出題までの秒数**（0〜600）を入力します。
3. 数秒後に最初の問題が出題され、ボタンが緑の「🤖 オート出題：ON（10秒後）」に変わります。

その後は、「出題 → 締切 → 正解発表 → 設定した秒数待つ → 次の問題」の順に進みます。

- **オート正解発表もONにしておくと、最後まで完全に自動で進行します。** オート正解発表がOFFの場合は、締切後に運営が「📢 正解発表」を押すと、設定した秒数後に次の問題が出題されます。
- 待っている間は、パネルの「👉 次の操作」に「第4問が あと8秒 で自動で出題されます」のように表示されます。
- 「⏹️ 締切」で早めに締め切ることもできます。
- オート出題中は、手動の出題ボタンと「⏭️ 次の問題」はロックされます。
- **停止するとき**は、ONのボタンをもう一度押し、確認ダイアログで「停止する」を押します。出題中の問題は、停止しても締切まで回答を受け付けます。
- すべての問題を出題すると、自動で停止します。
- オート出題は、Botを再起動すると停止した状態に戻ります（オート正解発表の設定は残ります）。

### オート正解発表

ONにすると、問題が締め切られてから設定した秒数が経つと、自動で正解が発表されます。

1. 「⏱️ オート正解発表：OFF」を押します。
2. 設定ウィンドウで、締切から正解発表までの秒数（0〜600）を入力します。0 にすると、締切と同時に発表されます。
3. ボタンが緑の「⏱️ オート正解発表：ON（10秒後）」に変わります。

- ONの間は、パネルの「👉 次の操作」に「第3問の正解は あと8秒 で自動で発表されます」のように表示されます。
- 自動発表を待たずに、「📢 正解発表」で先に発表することもできます。
- **停止するとき**は、ONのボタンをもう一度押し、確認ダイアログで「停止する」を押します。発表待ちの問題がある場合、その自動発表も取り消されるので、「📢 正解発表」で発表してください。
- 設定はBotを再起動しても残ります。リセットしても設定は変わりません。

### 事故防止のしくみ

**ボタンは、今押せるものだけが有効になります**（押せないボタンは灰色で表示されます）。基本の流れは「出題 → 締切 → 正解発表」です。

| 状況 | 押せるボタン |
|---|---|
| 回答受付中 | ⏹️ 締切 など（**出題ボタン・次の問題・正解発表はロック**） |
| 締切後、正解発表前 | 📢 正解発表 など（**出題ボタン・次の問題はロック**） |
| 正解発表後 | 出題ボタン、⏭️ 次の問題 など（同じ問題の正解発表は押せません） |

**正解発表をするまで、次の問題は出題できません。** 正解発表を忘れて次に進んでしまうことを防ぎます。


- 回答受付中の問題があるときやオート出題中は、出題ボタンや「次の問題」を押しても出題されません（二重出題の防止）。
- 回答受付中は正解発表ができません（前の問題の正解を誤って発表することを防止）。同じ問題の正解を2回発表することもできません。もう一度発表したいときは `/quiz reveal` を使います。
- 「締切」「リセット」と、オート機能の停止は、確認ダイアログで実行ボタンを押すまで実行されません。確認ダイアログは60秒間何も押さないと消えます。
- ボタンで操作すると、「○○ さんが第3問を出題しました」のように、誰が何をしたかがパネルのチャンネルに記録されます（正解は記録されません）。
- 押した本人にだけ表示されるお知らせ（「受付中の問題はありません」など）は、しばらくすると自動で消えます。

## 7. コマンド一覧

すべて「クイズ運営」ロールを持つ人だけが使えます。

### 出題

| コマンド | 内容 | 例 |
|---|---|---|
| `/quiz ask` | 自由入力の問題を出題 | `/quiz ask question:日本一高い山は？ answer:富士山\|ふじさん seconds:60` |
| `/quiz ox` | ○×問題を出題 | `/quiz ox question:富士山は3000m以上？ answer:○ seconds:20` |
| `/quiz choice` | 選択式（2〜4択）を出題 | `/quiz choice question:… a:… b:… c:… d:… answer:B seconds:30` |
| `/quiz load` | 問題リスト（XML・JSON）を登録 | `/quiz load file:（ファイルを添付）` |
| `/quiz next` | 登録済みの次の1問を出題 | `/quiz next` |
| `/quiz autorun` | オート出題を開始（パネルの「🤖 オート出題」と同じ） | `/quiz autorun interval:10` |
| `/quiz stop` | オート出題を停止 | `/quiz stop` |
| `/quiz close` | 受付中の問題をすぐ締め切る | `/quiz close number:3` |

- 自由入力で複数の正解を認めるときは `|` で区切ります。
- 全角／半角、大文字／小文字、ひらがな／カタカナ、空白の違いは自動で同じ答えとみなします。
- 問題文の中で `\n` と書くと改行になります。
- `choice` の c・d を省略すると2択・3択になります。
- `autorun` の `interval` は、正解発表から次の出題までの秒数です。
- `ask`・`ox`・`choice` に `note:〜` を付けると、正解発表で表示する補足を登録できます。

### 集計・発表

| コマンド | 内容 | 例 |
|---|---|---|
| `/quiz accept` | 別解を正解に追加し、その回答者を全員正解にする | `/quiz accept number:3 answer:漱石` |
| `/quiz judge` | 特定の人の正誤を手動で変更 | `/quiz judge number:3 user:@○○ correct:True` |
| `/quiz result` | 集計結果を `#クイズ集計` に出し直す | `/quiz result number:3` |
| `/quiz reveal` | 正解を出題チャンネルで発表（表示する項目は「⚙️ 表示設定」に従う） | `/quiz reveal number:3` |
| `/quiz ranking` | ランキングを集計 | `/quiz ranking public:True` |
| `/quiz reset` | 全データを消去 | `/quiz reset confirm:RESET` |
| `/quiz panel` | 操作パネルを設置 | `/quiz panel channel:#クイズ出題` |

### 集計結果の見方

- **問題ごとの結果**：正解、回答人数、正解者（回答の早い順・所要秒数つき）、不正解者とその回答。○×・選択式は選択肢ごとの人数も表示されます。
- **ランキング**：正解数の多い順。同点は同じ順位です。成績欄は第1問から順に `○`＝正解、`×`＝不正解、`－`＝未回答。

## 8. 問題リスト（XML）の書き方

メモ帳などのテキストエディタで作成し、拡張子を `.xml`、文字コードを **UTF-8** にして保存します。`samples\questions_sample.xml` をコピーして書き換えると簡単です。

```xml
<?xml version="1.0" encoding="UTF-8"?>
<quiz>

  <question type="text" seconds="60">
    <text>日本で一番高い山は？</text>
    <answer>富士山</answer>
    <answer>ふじさん</answer>
    <note>標高は3776メートルです。</note>
  </question>

  <question type="ox" seconds="20">
    <text>富士山の高さは3000メートル以上である。○か×か？</text>
    <answer>○</answer>
    <note>富士山の標高は3776メートルのため。</note>
  </question>

  <question type="choice" seconds="30">
    <text>「吾輩は猫である」の作者は？</text>
    <choice>森鴎外</choice>
    <choice>夏目漱石</choice>
    <choice>芥川龍之介</choice>
    <choice>太宰治</choice>
    <answer>B</answer>
  </question>

</quiz>
```

| 書き方 | 内容 |
|---|---|
| `<quiz>` 〜 `</quiz>` | 全体をこのタグで囲みます |
| `<question>` 〜 `</question>` | 1問分。上から順に出題されます |
| `type="…"` | `text`（自由入力）／`ox`（○×）／`choice`（選択式）。省略すると `text` |
| `seconds="…"` | 回答時間（秒）。省略すると自由入力は60秒、○×・選択式は30秒 |
| `<text>` | 問題文 |
| `<choice>` | 選択式の選択肢。2〜4個書き、上から A・B・C・D に対応します |
| `<answer>` | 正解。複数の正解を認めるときは `<answer>` を複数書きます |
| `<note>` | 正解発表のときに表示する補足（省略可） |

- **改行**：`<text>` や `<note>` の中で改行すると、そのまま改行として反映されます。行頭の字下げ（空白）は自動で取り除かれます。
- **○×の正解**は `○` か `×` で書きます。
- **選択式の正解**は、選択肢の文ではなく `A`〜`D` の記号で書きます。
- **記号の注意**：文中で `&` `<` `>` を使うときは、それぞれ `&amp;` `&lt;` `&gt;` と書きます（例：`A&amp;B` → 表示は「A&B」）。

### JSONで作る場合

これまでのJSON形式（`samples\questions_sample.json`）も引き続き使えます。ファイルの拡張子が `.json` なら、JSONとして読み込まれます。

## 9. 困ったときは

| 症状 | 原因と対処 |
|---|---|
| 起動時に `403 Forbidden (error code: 50001): Missing Access` | `GUILD_ID` が間違っているか、招待時に `applications.commands` が選ばれていません。サーバーIDを確認し、「2-3」の手順で招待し直してください。 |
| 起動時に `KeyError: 'DISCORD_TOKEN'` など | `start.bat` の設定が抜けています。`set` の行を確認してください。 |
| 起動時に `Improper token has been passed` | トークンが間違っています。Developer Portal で再発行して `start.bat` に貼り直してください。 |
| `py` が見つからないと表示される | Pythonのインストール時に「Add python.exe to PATH」にチェックが入っていません。Pythonを入れ直してください。 |
| `/quiz` コマンドやパネルのボタンが表示されない | Discordアプリで Ctrl + R を押して再読み込みしてください。 |
| 起動時に `AttributeError: module 'discord.ui' has no attribute 'FileUpload'` | ライブラリが古いです。ルートフォルダで `py -m pip install -U -r app\requirements.txt` を実行してください。 |
| 出題ボタンを押しても「回答受付中です」と出る | 前の問題が締め切られるまで待つか、パネルの「⏹️ 締切」で締め切ってください。 |
| 「このコマンド（ボタン）は『クイズ運営』ロールの人だけが使えます」 | 実行した人に「クイズ運営」ロールを付与してください。 |
| 操作パネルが2つ表示される／メッセージが二重に投稿される | Botが2つ同時に起動しています。黒い画面をすべて閉じてから、`start.bat` を1つだけ起動してください。現在のバージョンでは2つ目は起動できず、余分なパネルも自動で削除されます。別のPCでも同じBotを起動していないか確認してください。 |
| 起動時に「このBotはすでに起動しています」と表示される | 別の黒い画面でBotが動いています。そちらを使うか、停止してから起動し直してください。 |
| ボタンを押すと「インタラクションに失敗しました」 | Botが停止しています。`start.bat` で起動してください。 |
| 起動時に `can't open file ... quiz_bot.py` | `start.bat` の最後から2行目が `py app\quiz_bot.py` になっているか、`quiz_bot.py` が `app` フォルダにあるかを確認してください。 |
| `/quiz panel` で「Botの権限が足りない」と表示される、または `403 Forbidden (error code: 50001): Missing Access` | 非公開チャンネルにBotが参加していません。チャンネルの編集 →「権限」→「メンバーまたはロールを追加」でBotを追加し、「チャンネルを見る」「メッセージを送信」「埋め込みリンク」「メッセージ履歴を読む」を許可してください。 |
| 集計結果が `#クイズ集計` に投稿されない | `RESULT_CHANNEL_ID` が間違っているか、Botにそのチャンネルの閲覧・送信権限がありません。 |
| 「ロード」で「読み込みに失敗しました」 | 問題リストの書き方に誤りがあります。エラーメッセージの「○行目付近」「○問目」を確認してください。XMLでは、タグの閉じ忘れ（`</answer>` など）や、文中の `&` `<` `>` をそのまま書いていないかを確認してください。 |
| トークンを他人に見られてしまった | Developer Portal の「Bot」→「Reset Token」で再発行し、`start.bat` を書き換えてください。古いトークンは無効になります。 |
